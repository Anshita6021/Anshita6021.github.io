# Anshita Garg — Portfolio

A clean, recruiter-friendly personal portfolio built with plain HTML, CSS and JavaScript.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- GitHub Pages

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish on GitHub Pages

1. Create a public repository named `Anshita6021.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

The site will be available at:

`https://anshita6021.github.io`

## Edit the portfolio

Most content lives in `index.html`.

- `index.html` — text, sections, links and timeline
- `style.css` — layout, typography, spacing and visual design
- `script.js` — small interactive behaviour
- `assets/` — optional images/icons
