# Editing Guide

This portfolio is deliberately simple to maintain in VS Code.

## 1. Change text

Open `index.html` and search for the section you want to update:

- Hero / introduction
- About
- Experience
- Projects
- Patents & research
- Certifications
- Toolkit
- Beyond work
- Contact

## 2. Change links

Search for the existing GitHub, LinkedIn or `mailto:` URL and replace it with the new destination.

## 3. Change the design

Open `style.css`.

The main areas are grouped around navigation, hero, sections, cards, timeline, buttons and responsive rules.

## 4. Add images

Place images in `assets/` and reference them from `index.html` with a relative path such as `assets/profile.jpg`.
